# noobenkyo 剧本

noobenkyo 的听力是一集一集的广播剧。每个世界有设定和可出场的角色；一集有标题、梗概和若干行，每一行是一个人说的一句话，日语和中文各一份，app 用角色的声音合成语音。你写的剧本用 `noobenkyo listening send` 送进 app 的剧本预览，用户确认以后才存。

## 流程

1. `noobenkyo listening worlds`：有哪些世界。
2. `noobenkyo listening episodes 世界`：这个世界的每一集，带 uuid、集数、标题、梗概、行数和字数（char_count，日语和中文加起来）。决定哪些集要看全文：通常是最近的、和这次关系最紧的几集；其余看列表里的梗概就够了。
3. `noobenkyo listening context 世界 --after 集的uuid --after 集的uuid`：世界的设定、主要角色（名字、读音、性别、年龄、身份），以及选中的那几集的全文。--after 写的顺序就是剧情的先后。续写一集时加 `--append 集的uuid`，带上这一集已有的内容。
4. 按用户给的引子写剧本，写进文件，例如 ep.json。长短、谁主演都看引子。
5. `noobenkyo listening check ep.json`：有输出就按提示改，再查，直到没有输出。
6. `noobenkyo listening send ep.json --world 世界`（新的一集），或者 `--append 集的uuid`（续写）。send 会再查一遍剧本和世界，有问题就不送。

## 格式

```json
{ "title": "…", "summary": "…", "lines": [ { "speaker": "…", "ja": "…", "zh": "…" } ] }
```

- title、summary：中文，不能为空。
- lines：至少一行；每一行的 speaker、ja、zh 都不能为空。
- 多出来的字段会被忽略。
- 续写：lines 只写新的行，接在这一集的末尾；summary 换成覆盖整集（旧的加新的）的梗概；title 不会用到，照抄原来的标题就行。

## 写法

- **speaker**：
  - 主要角色说话时，原样写 context 里的名字。
  - 旁白写「旁白」。
  - 其他人随便写一个称呼，例如「店員」「客」；同一个人在整集里用同一个称呼。他们会自动配上世界里次要角色的声音。
- **一行只放一个人说的话。** 叙述交给旁白，单独成行。
- **ja**：
  - 提到主要角色的名字时写读音（假名），例如 みさき；中文里写名字（美咲）。
  - 容易念错的地方标读音，写成 `{写法|读音}`，读音只能有假名，例如 `{上手|うわて}`。要标的：这里的读法不是这个写法最常见的读法（上手 うわて、人気 ひとけ、生物 なまもの、一日 ついたち），少见的人名、地名、店名。按最常见的读法念就对的词不用标。
  - 每个标记都要完整；标记以外不能有单独的 `{`、`|`、`}`。
  - 不要写（笑）（小声で）这类括号里的说明，会被念出来。语气靠台词本身和标点。
- **zh**：自然的中文，和这一行的日语对应。
- **title**：简短。
- **summary**：写清楚发生了什么、人物之间的关系有什么变化。以后写续集时会拿它参考。
- 人物的言行要符合各自的身份和常识，情绪符合日常，不要夸张。故事讲完就结束，不要重复已经写过的内容。

## 例子

```json
{
  "title": "海边的早晨",
  "summary": "美咲在海边的便利店遇到同学健二，两人约好放学后一起去看灯塔。",
  "lines": [
    { "speaker": "旁白", "ja": "{潮風|しおかぜ}が{吹|ふ}く、{春|はる}の{朝|あさ}。", "zh": "海风吹拂的春日早晨。" },
    { "speaker": "店員", "ja": "いらっしゃいませ。", "zh": "欢迎光临。" },
    { "speaker": "美咲", "ja": "あれ？けんじくん、こんな{時間|じかん}にどうしたの？", "zh": "咦？健二，这么早你怎么在这儿？" },
    { "speaker": "健二", "ja": "{部活|ぶかつ}の{朝練|あされん}だよ。みさきこそ{早|はや}いな。", "zh": "社团晨练啊。美咲你也挺早的嘛。" }
  ]
}
```

## check 的输出

一条问题一行，例如：

- `title 为空`、`缺少 lines`
- `第 2 行：speaker 为空`
- `第 1 行 ja：读音标记 {上手|うわて 没有闭合`

行号就是 lines 里的第几行，从 1 开始。用户在预览里说"第 12 行"，也是这个行号。

没有输出、退出码是 0，就是通过。退出码 1 表示有问题；退出码 2 表示命令没能运行，原因在标准错误里。send 还会查世界在不在、旁白和主要角色齐不齐、续写的那一集在不在，这些问题也按退出码 1 列出。
